# House-price-prediction-
House Price Prediction is a machine learning project that aims to estimate the price of a house based on various features such as area, number of bedrooms, number of bathrooms, and other relevant factors. It is a supervised learning problem, where the model is trained on historical data containing house features and their corresponding prices.
House Price Prediction Expert System (Prolog)
🧠 Project Overview

This project is a rule-based expert system developed using Prolog to estimate house prices. It predicts the price of a house based on factors such as location, size, condition, and market trends.

Unlike machine learning models, this system uses logical rules and facts to compute the final price.

🎯 Objectives
To understand logic programming using Prolog
To build a rule-based expert system
To estimate house prices using predefined factors
To simulate real-world decision-making using logical inference
⚙️ Technologies Used
Prolog (SWI-Prolog / OneCompiler Prolog)
📂 Project Structure
Facts
Define base prices and multipliers for different house attributes
Rules
Calculate final house price using mathematical expressions
Main Predicate
Executes the program and displays the result
📊 Factors Considered
Factor	Description
Location	downtown, suburbs, rural
Size	small, medium, large, mansion
Condition	needs_work, good, renovated
Market Trend	buyer_market, neutral, seller_market
🧮 Price Calculation Formula

The estimated house price is calculated using:

Final Price = Base Price × Size Factor × Condition Factor × Market Factor

🚀 How to Run the Program
▶️ Using OneCompiler:
Select Prolog language
Copy and paste the code
Click Run
Execute the query:
?- main.
▶️ Using SWI-Prolog:
Save file as:
house_price.pl
Load file:
?- consult('house_price.pl').

?- main.
